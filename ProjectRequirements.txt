We are creating an OBDII diagnostic and command utility intended for use with a 2015 Ducati Scrambler motorcycle.

Requirements:
[R1 Runtime target]: The app shall run on a raspberry pi target with a 480x320 touchscreen display.
[R2 Hardware interface]: The app shall support the ELM327 PC-to-OBD hardware interface
[R2.1 Hardware interface detection]: The app shall autodetect an ELM327 connected to the raspberry pi via USB virtual com port
[R3 Communication protocol]: The app shall communicate to the vehicle using the ISO 11898 / ISO 15765-4 (OBD-II) protocol
[R4 ECU Target]: The app shall support the Continental M3C ECU for the 2015 Ducati Scrambler Icon 800 cc motorcycle
[R5 Status bar]: The app shall always display a status bar a the bottom of the screen with the ELM327 connection status, COM port ID, and a button to connect or disconnect
[R6 Tabbed GUI] The GUI shall have 2 tabs: Main and About
[R7 Main Tab] Upon an successful connection the main tab will display the vehicle VIN read from the ECU, a list of any active fault codes
[R8 About Tab] The about tab shall display the software version, and a copyright notice attributed to Bryan Hansen and GPL license information

Constraints:
[C1]: The app will be written in python
[C2]: The raspberry pi target can be found at 192.168.68.186; Username: pi, Password: sup3rdup3r
